# README File

*If you need to create a README file for your data deposition or to save documentation together with your data, you do not have to fill in the information twice. Just print the answers from the already filled DMP. Check that all sections are answered or remove what is not applicable. The answers that are available in the relevant Knowledge Model will be printed into the readme file. You can export it the same way you export any document template format through the application.*

The document template produces a dataset README file in Markdown, plain text and JSON from a project based on the Knowledge Model of the Czech National Repository Platform for Research Data.

This document template was based on the template authored by the [Collective of Data Stewards of the Czech Data Stewards Community](https://github.com/Czech-Data-Steward-Community/README_FILES/blob/main/Collective_datastewards.md) which is licensed under a [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). Code generation and Jinja2 adaptation performed with AI assistance.

## Issues and Contributing

This document template for DSW is available as open-source via GitHub Repository [dsw-nrp/readme-template](https://github.com/dsw-nrp/readme-template), you can [report issues](https://github.com/dsw-nrp/readme-template/issues) there and fork it for customizations or contributions.
